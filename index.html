ANTES DE ESCOLHER

Uma casa cheia
de perguntas boas.

Como escolher o tamanho de uma rede?

Confira o espaço disponível e a distância entre os pontos de fixação. As medidas específicas deste catálogo são demonstrativas e devem ser confirmadas pelo fornecedor antes do uso comercial.

As fotos mostram produtos reais à venda?

As imagens são fotos fotorrealistas geradas para este portfólio. Elas não foram verificadas com fornecedores e servem apenas para demonstrar o visual do catálogo.

Os produtos têm estoque disponível?

Este projeto é uma demonstração de portfólio. Os níveis de estoque exibidos são simulados e não representam disponibilidade para compra.

Posso finalizar uma compra?

O carrinho demonstra a jornada de compra. Nenhum pagamento ou pedido real é processado nesta versão.
